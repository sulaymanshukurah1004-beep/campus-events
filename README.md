# CampusConnect

## About the Project
CampusConnect is a campus life platform that is student-focused and designed to help students discover campus events, explore activities, and stay connected with their campus community.

## Technologies Used
CampusConnect is built with:
- Next.js
- React
- TypeScript
- Tailwind CSS

## Features
- Home page
- About Us page
- Categories page
- Explore Events page
- My Events page

## Categories
- Technology
- Sports
- Faith
- Social

## Getting Started

To run the project locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Purpose
CampusConnect aims to make campus life more engaging by helping students discover opportunities, participate in activities, and build connections.
